# Frozen analysis inputs

The source is John A. Johnson's public 2005 IPIP-NEO archive (20,993 protocols), component `sxeq5` of https://osf.io/tbmh5/. See `sources.csv` for original download URLs and SHA256 checksums. The original archive was downloaded on September 29, 2026.

- `source_items_scored.rds`: only the 300 numeric item-response columns extracted from `ipip20993.sav`, preserving its original already-reversed scoring and missing-response zeros. This portable file contains no demographics or identifiers. The SPSS source stays in the local working project and is excluded from the ZIP.
- `responses_administered.rds`: derived full response matrix, with zeros converted to missing and negative-keyed columns reversed back to agreement with the displayed text. Regenerated by the import script.
- `DAT20993.doc` and `.txt`: author's codebook and extracted text.
- `IPIP-NEO-ItemKey.xls`: original full-number mapping of text, facets, domains and scoring directions. Its original row order is not questionnaire order.
- `IPIP-NEO-300_scoring.xlsx`: independent scoring-key check.
- `IPIP-NEO-300_questionnaire.docx`: independent full-wording check. Its text is re-extracted on each import.
- `official_facets.html`: reference copy of the official IPIP facet key.
- `items.csv` and `questionnaire_wording_check.csv`: derived item tables.
- `embedding_request.json`: exact 300 statements, each prefixed `Document: `, submitted to the locally served Jina model.
- `jina_response.json`: complete frozen response, with vector indexes and model identifier; `jina_embeddings.rds` is its derived numeric matrix.
- `seeds.csv`: resampling and permutation seed specification.

The matrix and JSON files contain frozen observations and model outputs; nothing is simulated. Source materials retain their original terms. IPIP item wording is public domain. No local Jina service or internet connection is needed to rerun the analysis.
