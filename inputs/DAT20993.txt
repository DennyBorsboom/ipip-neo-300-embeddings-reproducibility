Variables in the ipip20993.dat file are organized in tab-delimited format. The variables are SEX (1=male, 2-female), AGE (in years), I1 through I300 (item responses to the 300 items on the IPIP-NEO-300, FRIENDLI IMAGINAT TRUST SELFEFFI ANGER GREGAR ARTISTIC MORALITY ORDER DEPRESS ASSERTIV EMOTION ALTRUISM DUTIFUL SELFCONS ACTIVITY ADVENTUR COOPERAT ACHIEVE IMMODERA EXCITE INTELLEC MODESTY SELFDISC VULNERAB CHEERFUL LIBERAL SYMPATHY CAUTIOUS (30 facet scores), IPIPN IPIPE IPIPO IPIPA IPIPC (5 domain scores), RNDSPLIT (Jackson split-half intra-individual reliability coefficient), and RNDCORR (Goldberg Psychometric Antonyms).

The 300 item responses, I1 to I300, contain values from 1 to 5, with missing values coded as 0. For forward-scored items, the values 1 to 5 refer to the item responses Very Inaccurate, Moderately Inaccurate, Neither Accurate nor Inaccurate, Moderately Accurate, and Very Accurate. Reverse-scored items were recoded (1=5, 2=4, 4=2, 5=1) at the time the respondent completed the inventory, so values for these items can simply be added without recoding when scale scores are computed. But that also means that researchers interested in measuring the number of consecutive uses of the same response category will have to recode reverse-scored items to have the values correspond to Very Inaccurate = 1 through Very Accurate = 5.
